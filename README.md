# Автоматизированные тесты для Stellar Burgers

Этот проект содержит набор автоматизированных тестов для веб-приложения [Stellar Burgers](https://stellarburgers.nomoreparties.site). Тесты написаны с использованием **Python**, **Selenium WebDriver**, **Pytest** и **Allure** для генерации отчётов. Они проверяют основной функционал сайта, включая восстановление пароля, работу личного кабинета, оформление заказов и ленту заказов.

## Требования

Для запуска тестов необходимо установить следующее:

- **Python** 3.8 или выше
- Браузеры **Google Chrome** и **Mozilla Firefox** (последние версии)
- **WebDriver** для Chrome (ChromeDriver) и Firefox (geckodriver), совместимые с установленными браузерами
- Утилита **Allure** для генерации отчётов (опционально, если требуется просмотр отчётов)

## Установка

1. **Склонируйте репозиторий**:
   ```bash
   git clone <URL_репозитория>
   ```

2. **Создайте виртуальное окружение**:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости**:
   Убедитесь, что файл `requirements.txt` содержит следующие библиотеки:
   ```
   allure-pytest==2.14.0
    pytest==8.3.5
    requests==2.32.3
    selenium==4.31.0
    webdriver-manager==4.0.2
   ```
   Установите их командой:
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка WebDriver**:
   - Убедитесь, что **ChromeDriver** и **geckodriver** установлены и добавлены в переменную PATH.
   - Для автоматической загрузки драйверов можно использовать `webdriver-manager` (добавить в `requirements.txt`: `webdriver-manager==4.0.2`), но в текущем проекте предполагается ручная установка.

5. **Установка Allure** (для отчётов):
   - Скачайте и установите **Allure CLI** с [официального сайта](https://allurereport.org/docs/install-allure/).
   - Проверьте, что команда `allure` доступна:
     ```bash
     allure --version
     ```

## Структура проекта

- **`tests/`**: Тестовые файлы, разделённые по функциональности:
  - `test_main_functionality.py`: Тесты основного функционала (навигация, ингредиенты, заказы).
  - `test_order_feed.py`: Тесты ленты заказов.
  - `test_password_recovery.py`: Тесты восстановления пароля.
  - `test_personal_account.py`: Тесты личного кабинета.
- **`pages/`**: Классы Page Object для взаимодействия со страницами сайта:
  - `main_page.py`
  - `login_page.py`
  - `forgot_password_page.py`
  - `personal_account_page.py`
  - `order_feed_page.py`
- **`locators.py`**: Локаторы для всех страниц, организованные по классам.
- **`conftest.py`**: Настройки фикстур Pytest (драйвер, создание тестового пользователя, страницы).
- **`requirements.txt`**: Список зависимостей проекта.

## Запуск тестов

1. **Запуск всех тестов**:
   ```bash
   pytest tests/
   ```

2. **Запуск тестов в конкретном браузере**:
   - Для **Google Chrome**:
     ```bash
     pytest tests/ --browser=chrome
     ```
   - Для **Mozilla Firefox**:
     ```bash
     pytest tests/ --browser=firefox
     ```

3. **Генерация Allure-отчёта**:
   
    - Для **Google Chrome**:
    ```bash
    pytest tests/ --alluredir=./allure-results-chrome
    allure serve ./allure-results-chrome
   ```

    - Для **Mozilla Firefox**:
    ```bash
    pytest tests/ --alluredir=./allure-results-firefox
    allure serve ./allure-results-firefox
    ```
   Первая команда сохраняет результаты в папку `allure-results`, вторая открывает отчёт в браузере.

## Покрытие тестов

Тесты покрывают следующий функционал **Stellar Burgers**:

### Восстановление пароля
- Переход на страницу восстановления пароля.
- Ввод email и переход к сбросу пароля.
- Проверка видимости поля пароля при клике на кнопку «Показать/скрыть».

### Личный кабинет
- Переход в личный кабинет.
- Переход в историю заказов.
- Выход из аккаунта.

### Основной функционал
- Навигация в разделы «Конструктор» и «Лента заказов».
- Отображение деталей ингредиента.
- Закрытие модального окна с деталями.
- Увеличение счетчика ингредиентов.
- Оформление заказа авторизованным пользователем.

### Лента заказов
- Отображение деталей заказа.
- Проверка заказов пользователя в ленте и истории.
- Увеличение счетчиков «Выполнено за всё время» и «Выполнено за сегодня».
- Появление заказа в разделе «В работе».

## Создание и удаление тестовых данных

- Тестовый пользователь создаётся через API (`POST /api/auth/register`) перед каждым тестом, где он нужен.
- После теста пользователь удаляется через API (`DELETE /api/auth/user`), чтобы обеспечить чистоту данных.

## Возможные проблемы и решения

- **Ошибка «WebDriver not found»**:
  - Убедитесь, что **ChromeDriver** и **geckodriver** установлены и добавлены в PATH.
  - Проверьте совместимость версий браузера и драйвера.

- **Тесты падают из-за недоступности API**:
  - Проверьте доступность сайта `https://stellarburgers.nomoreparties.site`.
  - Убедитесь, что интернет-соединение стабильно.

- **Allure-отчёт не генерируется**:
  - Убедитесь, что **Allure CLI** установлена и доступна в терминале.
  - Проверьте наличие папки `allure-results` после запуска тестов.

Чтобы создать корректный `requirements.txt`, выполните:
```bash
pip freeze > requirements.txt
```

Перед этим установите только необходимые зависимости:
```
pytest==8.3.2
selenium==4.25.0
requests==2.32.3
allure-pytest==2.13.5
```

Если вы используете `webdriver-manager` для автоматической загрузки драйверов, добавьте:
```
webdriver-manager==4.0.2
```
